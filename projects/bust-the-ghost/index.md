**Stack:** Unity, C#, Blender  
**Repo:** [BustTheGhost](https://github.com/Adnane-Ahroum/BustTheGhost)

An interactive game that teaches **Bayesian inference** by having players update beliefs about a hidden ghost's
location based on noisy sensors.

## Highlights

- Encodes priors and likelihoods; shows posterior updates visually
- Balances gameplay with pedagogical clarity
